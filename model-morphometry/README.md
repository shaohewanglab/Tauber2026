# Model acircularity and bud-count plots

From the repository root:

```bash
python model-morphometry/reproduce_model_plots.py
python model-morphometry/verify_model_plots.py
```

The root `python reproduce_plots.py` command includes these four model exports.
PDF and SVG are generated by default, with PDF-rendered PNG previews and CSVs.
Rendering uses the root requirements, shared `plot_style.py`, Arial, TeX Live
Poppler and Ghostscript, as described in the root README. PDF and SVG text is
converted to vector outlines; viewing or placing exports needs no installed
fonts. Edit label wording in the scripts and regenerate the figures.

Figure 4 exports only the selected Paul Tol Bright style (`-tol-bright`). Tol colors follow purple, blue, cyan, green,
yellow, red as z increases. The 4A gray theoretical band is omitted; y spans
0-110% and the raised 6 pt legend has two columns of three entries. 5D/5E share
the 5F frame height of approximately 0.9332 inches. Axis labels use 7 pt except
4E, which uses 6 pt, matching combined experimental 4F/G.
Figure 4A uses 4B's exact 40.80813036 mm plotting-frame width,
with aligned frame edges and the unchanged 1.95 x 0.96 inch full canvas.
The endpoint tick label 1.5 is right-aligned so it fits inside that canvas.

In 4E the right edge of `z:` matches the left edge of the y tick labels.
Observations are hollow 2 pt circles with 0.35 pt colored outlines and white
interiors. Mean and SD marks are black and drawn above the observations,
matching 4F/G. Swarms accommodate the larger circles within the fixed frame.
All 18 model bud counts are complete: three independent simulations per thickness,
counted at tau/tau_g = 1.5. The updated CSV shared on 18 October 2026 is copied
unchanged; means and sample SD are recomputed for validation before plotting.
See [the internal note](../INTERNAL_NOTES.md) for the values and data history.

4E includes five two-sided, single-step Dunnett comparisons of mean bud count
against the thinnest z = 0.0005, matching the comparison-of-means approach in
experimental 4F/G. Each group requires at least two independent simulations;
an incomplete family is labeled `n/a` until every group meets this requirement.
No observations or variances are imputed. All groups currently have three runs.
Dunnett-adjusted P values are 0.509792, 0.00141821, 0.00000391365,
0.000000841974 and 0.000000841974, giving `ns`, `**`, `****`, `****`, `****`.
No additional Holm correction is applied. The normal/common-variance
approximation is stated explicitly; three runs do not establish this assumption.
Zero observed variance in some groups is allowed because the pooled variance is
positive (1/3, residual df = 12). An unbudded shape has N_buds = 1.

The plot is accompanied by `Fig4E-model-bud-count-comparisons.csv`,
`Fig4E-model-bud-count-statistics.txt` and `Fig4E-model-bud-count-statistics.json`
in `results/`. These record sample counts, signed t statistics, marginal t P,
Dunnett-adjusted P, pooled variance, baseline, method and assumptions. The shared
root `dunnett_statistics.py` uses deterministic normal/chi-square quadrature.
See [Dunnett method guidance](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.dunnett.html).

## Source inputs and calculation conventions

Only the eight used coordinate archives and the bud-count CSV are included in
`ModelData/`. Seven archives are no-washout references (six plotted thicknesses
plus z = 0.015); one is the z = 0.015 washout simulation. Unused shared files,
images and system metadata are excluded. The four unchanged supplied scripts
are in `original_scripts/`. `source-data-manifest.json` verifies all 13 files;
the root manifest also verifies the nine model data inputs.

The source contours have 400 nodes and 399 consecutive-node edges. Area is
computed by closing the contour with a chord; perimeter sums the consecutive
edges without that chord, exactly as in Justin's scripts. Acircularity is
`chi = perimeter / (2*sqrt(pi*area)) - 1`. Curves display
`100 * (chi - chi_baseline)`. Saved frames are spaced by 0.01 in model time;
the integration step in archive filenames is not substituted for saved time.
5E resets both time and acircularity at zero-indexed frame 75 (tau = 0.75);
5D retains the original frame-0 baseline.

`validation/original-curves.json` is the frozen reference captured from the
supplied scripts with only input paths and output handling redirected. Default
reproduction preserves that fixture. Every numerical curve is checked against
it before export; the independent verifier checks all 11 exported original
curves, source hashes, sample counts, mean/SD, color order and canvas sizes.
