Reproduce the three updated plots shared by Justin:

| Figure | Output PDF | Cohorts |

The 28 unchanged source tables contain 260 observations and total 10,590 bytes.
They come from `PaperData/Results_MeshVoxelization`, retaining original

## Reproduce

From the repository root, using the root Python requirements:

```bash
python mesh-morphometry/reproduce_mesh_plots.py
python mesh-morphometry/verify_mesh_plots.py
```

Or run `python reproduce_plots.py` for all manuscript plots and the washout marker variants.
Select one mesh plot with `--figure 2`, `--figure 4`, or `--figure 5`.
`--output-dir` selects an alternative destination.

PDF and SVG are both generated by default, along with PNG previews and summary CSVs.
Figure 4B exports only the selected `-tol-bright` version. Use `--figure 4` to regenerate it.

Default rendering combines **Arial text with Justin's Arev math**. It requires
Arial installed locally, TeX Live tools `xelatex`, `xdvipdfmx` and `dvisvgm`,
Poppler's `pdftoppm`, and Ghostscript's `gs`. The TeX packages are `fontspec`,
`amsmath`, `arevmath`, `pgf` and `standalone`. Fonts are not bundled. All text
is converted to vector outlines in PDF and SVG, so viewing or placing exports
requires no installed fonts. Arial and Arev remain necessary for regeneration.
PNG is rendered from the outlined PDF at 300 dpi. Label wording remains in the
scripts, and the exported glyphs are editable as shapes.

For a system without TeX, use the approximate typography fallback:

```bash
python mesh-morphometry/reproduce_mesh_plots.py --text-rendering mathtext
```

Add `--font "DejaVu Sans"` if Arial is unavailable. The fallback changes the math
typography and may reduce label padding to preserve the requested canvas/frame
geometry, while retaining all numerical results. Poppler is still used for PNG
previews; this mode does not require TeX.

## Presentation

The shared root `plot_style.py` sets axis labels to 7 pt, legends and tick labels
to 6 pt, frames to 0.6 pt and means to 1 pt. Figure 4B individual curves use
0.5 pt lines at 30% opacity in the selected color style, making opaque mean curves
more prominent; the SD bands retain 20% opacity. Other individual mesh curves
retain 0.8 pt lines at 50% opacity. Figures 2C and 5F retain Justin's colors; Figure 4B uses Paul Tol Bright. Textual units, percentages, condition
labels and descriptive subscripts use Arial; mathematical symbols use Arev.
TeX point conversion is compensated to match native Matplotlib font sizes.
Figure 4B displays -10 to 110%, matching Figure 4A's 110% upper limit while
retaining negative observations. This presentation override leaves all curves,
SD bands and exported summary values unchanged.

Figure 4B uses blue (`#4477AA`), green
(`#228833`) and red (`#EE6677`) for 0, 1 and 5 µM BB-94. These match z = 0.001,
0.005 and 0.01 in the model 4A plot. The shared thickness palette runs purple,
blue, cyan, green, yellow, red as thickness increases. Titration 4E/F/G use the
same spectral order in the selected palette, with gray experimental controls.
The 4B legend is shifted up by 3 pt, retaining the original
canvas, frame, fonts, data curves and SD bands.

Model panels are generated by `model-morphometry/reproduce_model_plots.py`.
The count and intensity panel sizes are also specified in `figure_sizes.json`.
Sizes default to the full exported canvas with a 1 pt outside margin. Figure 2C
uses a 0.5 pt minimum outside margin to retain its exact frame with the added label gap.
Axis label gaps were increased by 1 pt (2 pt in mesh plots; 5 pt in count/intensity plots). Fonts
retain fixed physical sizes. Optional `frame_mm` specifies an exact plotting
frame within that canvas. `frame_height_mm` fixes only the frame height;
`frame_height_as` links that height to another panel. Export does not crop or
rescale the requested canvas.

## Calculations retained from Justin

- Time is the recorded `time_min / 60`, without resampling.
- Figure 2: green is `100 * ((V/V0)**(2/3) - 1)`; orange is
  `100 * (A/A0 - 1)`. Green is the isotropic surface expansion, ΔS-tilde
  with subscript “iso”; orange is the measured surface expansion, ΔS-tilde.
  This corrects the reversed legend labels in the supplied script/PDF without
  changing either curve, color or summary value. The shared y-axis label is
  “Normalized surface expansion”, wrapped over two lines at 7 pt to retain
  the exact canvas and frame dimensions. Values remain expressed as percentages.
- Asphericity is `chi = 1 / (pi**(1/3) * (6*V)**(2/3) / A) - 1`.
  Figures 4 and 5 plot `100 * (chi - chi0)`.
- Short series are padded with NaNs. Means and population SD (`ddof=0`) use
  available values at each row. There is no smoothing, SEM or inferential test.
- Justin averages by row and uses the first longest series' time axis.
  Some raw timestamps differ by up to five minutes; this behavior is preserved.
- The missing volume at 800 min in `250916-SMG1-BB94-washout` remains NaN,
  retaining the original line gap and excluding that observation from its mean.
- Rows beyond the displayed 0–16 h window are retained. Later means can contain
  fewer glands; each exported summary CSV records the actual `n`.

## Verification and attribution

The plotting script consolidates Justin's three `create_*` scripts and the
used PNAS helpers in `PlotLibrary.py`. Original script hashes and the supplied
PDF hashes are recorded in `validation/provenance.json`.

`validation/expected-curves.json` was captured directly from Justin's original
scripts with only paths and noninteractive output handling changed.
The verifier checks 28 input hashes, 56 individual/mean curves, 7 SD polygons
and 87 summary rows at `rtol=1e-10`, `atol=1e-12`. Type sizes, line widths and
layout intentionally use the requested common presentation. The verifier also
checks the corrected Figure 2C legend-to-quantity mapping and shared y-axis title.
It separately checks all 23 recolored Figure 4B curves and three SD bands,
their z-matched colors, and equality of the two exported summary tables.

Before restyling, the consolidated script rendered identically to the originals.
All 63 data paths also agreed with the supplied Inkscape-exported PDFs within
0.0024 pt. That audit established numerical provenance before restyling.
